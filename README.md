# 🛍️ Deals Bazaar - Premium Affiliate Store

A professional affiliate product showcase website with auto-sync admin panel.

## ✨ Features

- 🎨 **Premium UI/UX** - Modern glassmorphism design
- 🔍 **Search & Filter** - By platform, category, discount
- 📱 **Fully Responsive** - Works on all devices
- ⚡ **Auto-Sync** - Admin panel syncs directly to GitHub
- 🔐 **Secure Admin** - Password protected admin panel
- 🏷️ **Discount Badges** - Automatic discount calculation
- ⭐ **Ratings & Reviews** - Product ratings display
- 💰 **Price Comparison** - Show original vs selling price
- 🚀 **Fast Loading** - GitHub Pages hosted, CDN delivered
